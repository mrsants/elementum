# Elementum

Elementum is a cross-platform scientific desktop application for spectral
analysis of water samples. It focuses on heavy metal detection, peak
identification, and data visualization. Built with Rust and Tauri, it
provides a fast, stable, reliable environment for laboratory work.

The project aims to be transparent, reproducible, and useful for
research, field testing, and educational purposes.

## Features

* CSV spectrum loading
* Peak detection
* Interactive plotting
* Basic reporting
* Local storage
* Cross-platform builds (Linux, macOS, Windows)

## Goals

* Reliable scientific workflows
* Clean, efficient, maintainable code
* Open, auditable processing steps
